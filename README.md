# Handy Kit

마인크래프트 자바 26.3(Fabric)용 클라이언트 모드예요. 여러 서버를 탭으로 한꺼번에 열어 두는 기능을 중심으로, 로그 뷰어, 매크로, 메모장 같은 편의 기능을 jar 하나에 담았어요.

**NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**
마인크래프트 공식 모드가 아니며 Mojang, Microsoft 와 관계없어요.

## 받기

- **[최신판 jar 받기](https://github.com/tinymita2-pixel/handykit/releases/latest/download/handykit.jar)** (이 링크는 늘 최신판을 받아요). 받은 파일을 `mods` 폴더에 넣으면 돼요.
- 필요한 것: Minecraft 26.3, Fabric Loader 0.19 이상, Fabric API, Java 25
- 있으면 더 되는 것: ViaFabricPlus (서버 이송 때 그 서버 버전으로 들어가기), Mod Menu (모드 목록의 설정 버튼)
- 같이 두면 안 되는 것: 예전 단독 모드 logviewer, transferdetect, legacypackfix (기능이 이 모드에 들어 있어요)
- 파일 SHA-256 은 릴리스 설명에 있어요.

## 키

| 키 | 하는 일 |
|---|---|
| F6 (Shift+F6) | 다음 서버 탭 (이전 탭) |
| F7 | 로그 보기 |
| M | 설정 화면 |
| N | 메모장 켜고 끄기 |
| V, B | 좌클릭, 우클릭 오토 켜고 끄기 |
| F8, F9 | 동작 녹화 시작과 끝, 재생과 멈춤 |
| 키패드 1~9, 0 | 상용구 1~10 보내기 |

키는 설정 화면(M)이나 게임 조작 설정에서 바꿀 수 있어요.

## 되는 것

### 서버 탭

- 한 게임에 여러 서버를 열어 두고 화면 위 탭 줄에서 브라우저 탭처럼 바꿔요. 서버에 있는 채로 탭 줄의 + 로 다른 서버에 들어가면 지금 서버는 뒤 탭으로 남아요.
- 탭마다 다른 계정으로 들어갈 수 있어요. 마이크로소프트 계정을 더 붙이거나(로그인은 마이크로소프트 페이지에서 직접) 오프라인 서버용 이름을 쓸 수 있어요. 탭을 우클릭해서 "다른 계정으로 또 열기"도 돼요.
- **구석에 작게 보기**: 뒤 탭을 화면 오른쪽 위 작은 창(3개까지)에서 실제 화면 그대로 실시간으로 봐요. 채팅을 열면(T) 창을 끌어 옮기고, 왼쪽 아래 모서리를 끌어 크기를 바꾸고, 창 아래 입력 줄에 쳐서 그 서버로 채팅이나 명령을 보낼 수 있어요. 그림을 누르면 그 탭으로 가요.
- **리소스팩은 탭마다 따로**: 탭마다 그 서버가 보낸 팩으로만 보여요. 팩을 한 번 받아 두면 탭을 바꿀 때 다시 불러오지 않아서 멈추지 않고, 작은 창도 그 탭의 팩으로 그려요.
- 탭이 화면에 돌아오면 서버가 틀던 음악을 이어서 틀어요.
- 같이 입력(표시한 탭끼리 같은 채팅 보내기), 뒤 탭 알림(귓속말, 내 이름, 정한 단어), 끊기면 다시 접속, 접속 뒤 보낼 말, 지금 탭들을 세트로 저장하고 다시 열기, 뒤 탭 소리 듣기와 크기, 뒤 탭 시야 줄이기
- 싱글플레이 월드도 탭으로 뒤에 둘 수 있어요(한 번에 하나).

### 로그 뷰어 (F7)

- latest.log 와 날짜별 로그를 날짜, 서버별로 나눠 봐요. 메뉴 화면에서도 열려요.
- 모든 날짜를 한꺼번에 검색하고, 찾은 줄을 더블클릭하면 그날 로그 속 그 자리로 가요. 전체, 채팅, 경고, 오류 필터와 복사가 돼요.

### 매크로 (M)

- 오토클릭: 연타(초당 0.5~20번), 꾹 누르기, 공격 게이지가 찰 때마다
- 상용구 10개, 키워드 자동 응답(지연, 쿨타임)
- 동작 녹화와 재생: 이동, 시선, 클릭, 채팅, 상자 칸 클릭까지 녹화하고 한 번, 횟수, 무한 반복으로 재생해요. 자르기, 빠르게, 이어 붙이기, "이 말이 뜨면 계속", "아이템 N개가 될 때까지" 같은 편집이 돼요.
- 서명 없이 채팅 (기본 켜짐)
- "이 서버 전용 설정"으로 서버마다 다른 설정을 쓸 수 있어요.

### 메모장 (N)

게임 위에 메모 한 장을 띄워요. 채팅을 연 상태에서 옮기고 크기를 바꾸고, 눌러서 바로 고쳐요.

### 그 밖

- 이송: ViaFabricPlus 가 있으면 서버가 다른 서버로 보낼 때 그 서버가 쓰는 버전으로 들어가요.
- 옛 리소스팩: 1.21.x 팩의 코어 셰이더를 26.3 에 맞게 고쳐 쓰고, 그래도 안 되는 부분만 원래 셰이더로 되돌려서 팩이 통째로 꺼지거나 서버에서 튕기지 않게 해요.

## 알아 둘 것

- **서버 규칙**: 오토클릭, 매크로, 녹화 재생, 자동 응답, 여러 계정 동시 접속, 같이 입력, 서명 없이 채팅, 다른 버전으로 접속하기는 서버에 따라 금지일 수 있어요. 쓰기 전에 서버 규칙을 확인하세요. 서명을 강제하는 서버에서는 설정 "상용구" 첫 줄의 "서명 없이 채팅"을 꺼야 채팅이 돼요.
- **다른 계정 로그인**은 공식 마인크래프트 런처의 공개 로그인 ID 를 빌려 쓰는 비공식 방식이에요. 로그인은 마이크로소프트 페이지에서 직접 하고, 모드는 비밀번호를 보지 않아요. 마이크로소프트가 이 방식을 막으면 계정 추가가 안 될 수 있어요.
- **같이 입력**을 켠 탭끼리는 `/login` 같은 비밀번호 명령도 똑같이 나가요. 비밀번호를 칠 때는 같이 입력을 꺼 두세요.
- **뒤 탭 리소스팩**: 뒤 탭은 동의 창을 띄울 수 없어서 묻지 않고 받아요(서버 목록에서 팩을 "사용 안 함"으로 둔 서버만 거절). 탭 세트로 연 탭도 묻지 않고 받아요. 팩을 내려받을 때 보내는 이름은 탭 계정이 아니라 게임을 켠 계정이에요.
- **데이터가 가는 곳**: 계정을 더하거나 갱신할 때 마이크로소프트, Xbox, 마인크래프트 서비스. 그 밖에는 직접 연 서버들(ViaFabricPlus 가 있으면 버전 확인용 상태 질의 포함)과 서버가 보낸 리소스팩 주소뿐이에요. 통계 수집, 업데이트 확인은 없어요.
- **저장하는 곳**: `config/handykit/` (설정, 녹화, 서버별 설정, 계정). 다른 계정의 로그인 정보는 Windows DPAPI 로 암호화하지만, 같은 컴퓨터의 같은 Windows 사용자로 도는 프로그램은 풀 수 있어요. 이 폴더와 게임 로그(계정 이름, 서버 주소, 채팅이 남아요)는 남에게 보내지 마세요. "접속 뒤 보낼 말"에 비밀번호를 넣으면 그대로 저장돼요.
- 처음 팩을 받은 탭은 그 팩으로 한 벌을 만드는 데 1~3초쯤 걸려요(게임은 그동안에도 돌아요). 큰 팩은 더 걸려요.
- Iris 셰이더팩을 켜면 작은 창은 위에서 본 지도로 바뀌어요.

## 소스와 빌드

- 이 저장소의 `src` 가 릴리스 jar 의 소스예요. Java 25 가 있으면 `./gradlew build` (윈도는 `gradlew.bat build`)로 `build/libs/handykit-<버전>.jar` 가 나와요.
- 포크해서 고치고 나눠도 돼요. MIT 라이선스 고지만 남겨 주세요.
